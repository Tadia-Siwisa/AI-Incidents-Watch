# Research scripts

These programs mainly reproduce **historical October research work**, not the November 188-source category audit. They are kept here because code belongs separately from data.

- `build_factual_rebuild.py`: source-level verification and 46-family reconciliation.
- `analyze_incidents.py`: historical 46-family tables and archived exploratory-report figures.
- `build_research_pdf.py`: regenerates **archived Codex draft PDF**, not the authored published report.
- `build_master_reading_list.py`, `build_evidence_updates.py`, `build_wide_search_2.py`: generate historical Excel workbooks in `data/history/2026-10/`.
- `scan_evidence_radar.py` and `search_*.py`: discovery, not adjudication.
- `update_incident_intake.py`: unverified GitHub-issue intake.
- Other `retrieve_*.py` and `rebuild_register.py` scripts: supporting reproducibility.

Historical outputs do **not** automatically become the working research master.
