# Incident leads and incoming disclosures

**Unverified intake only.** This folder is not the reviewed research dataset.

- [incoming_evidence.json](incoming_evidence.json) — source-linked new disclosures and updates from automated reports or manual issue submissions.
- \`incoming_evidence.xlsx\` — separate Excel intake workbook regenerated from the JSON by GitHub Actions after a \`[Evidence]\` issue.
- [incident_leads.json](incident_leads.json) and [incident_leads.xlsx](incident_leads.xlsx) — earlier incident lead process using \`[Incident]\` issues; deliberately kept separate.
- [weekly_research_2026-10-28.json](weekly_research_2026-10-28.json) — historical lead notes.

**Do not promote an incoming report directly into data/working/**. The researcher reviews new versus existing cases, source authenticity, authorization claims, outcomes, and evidence gaps first.
