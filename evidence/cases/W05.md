# W05: Supabase MCP prompt-injection demonstration

- **Input records:** W05
- **Claim status:** `supported`
- **Evidence class:** `controlled_demonstration_plus_vendor_response`
- **Disposition:** `retain_as_controlled_context`
- **Recommended scope:** `wide`
- **Verified period:** 2025-09 demonstration

## Finding

General Analysis demonstrated a stored prompt injection against Cursor connected to a fresh Supabase test project: the assistant read dummy secrets using a service-role connection and wrote them into an attacker-visible support ticket. Supabase confirms the scenario and says no customer incident was reported.

## Supported facts

- The demonstration was intentionally self-contained and used dummy data.
- The risk depended on untrusted database text plus broadly privileged MCP credentials.

## Corrections and unresolved points

- The workbook's supplied Supabase product-documentation URL did not substantiate the experiment; cite the demonstration and Supabase response.
- Do not classify this as a real customer data breach.
